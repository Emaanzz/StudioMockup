# Astera Studio: Loopsy Analytics Mockup

## Overview
This is a responsive, clickable mockup of an analytics platform for Loopsy, a permanent jewellery brand. It demonstrates how a business owner can explore sales data, view dashboards, interact with charts, and manage data pipelines.

## How to Run
1. Download and extract the ZIP file.
2. Open `finalV.html` in any web browser.

## Main Features
- **Ask Studio:** Ask questions about business data and view generated responses and charts.
- **Dashboard:** View revenue, orders, average order value, and pop-up performance.
- **Interactive charts:** Pin charts to the dashboard and explore individual pop-up breakdowns.
- **Pipelines:** View workflow steps, inspect their settings, and make changes.
- **Pipeline error handling:** Identify and fix a failed step, then rerun the pipeline.

## Note
For personalisation, the sample data used is of my Jewellery Business, LOOPSY and is completely made-up and hardcoded just for this assessment.
